# Oracle handoff — 2026-08-20, run 6

Scope of this run: BL-19 only, commissioned unattended by the delivery driver.

## Decided

- **OD-18** resolves **BL-19** (with BL-5 as its parent evidence): after a
  subcommand name, `-h/--help` stays the dispatcher's. R1006's clause covers
  flags a subcommand *documents*, and no subcommand documents `--help`, so the
  ruling reads the requirement literally rather than carving an exception:
  `--help` is a flag the dispatcher recognises, so it is not among the
  arguments it forwards. Each subcommand's parser is built with
  `add_help=False`, so no command ever advertises a flag that cannot reach it.
  No requirement added or superseded; this is a clarifying decision on
  R1006's reading, the same shape as OD-14 and OD-17.

## What needs planning

pinned case in `tests/test_cli.py` (already in slice 1's file list): a
subcommand name followed by `--help` prints the top-level help. That is a test
inside the slice's declared files, not a plan change.
