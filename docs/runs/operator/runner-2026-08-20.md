## RN-3 — the 10% ruling exists only in a pull request comment

The owner rejected PR #133 (`R26`: the extraction cap moving to 15%) and
recorded the reasoning as a review comment: the cap **stays 10%**.

`docs/DECISIONS.md` is this project's record for exactly that, and its own
opening says a ruling is never left in chat. The rejected pull request carried
the `DECISIONS.md` entry, so rejecting it also rejected the record — the ruling
and its only written home travelled together and both were declined.

Nothing in the repository now says the cap is 10% **by decision**; it says so
only by never having changed. A future oracle or steward reading `R26` sees a
number with no ruling behind it and no note that raising it was already
considered and refused.

**Severity:** friction, but the recurring kind — this is the same
"durable-evidence gap" the web lane's oracle named unprompted for BL-16 and
BL-17: a decision whose evidence never lands beside it.
